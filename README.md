## About Me

I'm a Full-Stack Developer with an equal interest in DevOps. I enjoy building applications end-to-end and understanding how they are deployed, automated, and run reliably.

On the development side, I work with the MERN Stack to build clean and functional frontend and backend applications. On the DevOps side, I'm interested in containerization, automation, CI/CD, cloud technologies, and reliable deployment workflows.

I'm an IT graduate who enjoys solving problems methodically, learning new technologies, and working across both development and deployment.

Building full-stack applications, improving my DevOps skills, and learning how to build, deploy, and maintain applications efficiently.
